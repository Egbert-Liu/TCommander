tcommander_update_status
更新会话状态 (running/idle/needs-input/needs-confirm/error)
tcommander_list_sessions
列出所有会话及状态（含 emoji 标记）
tcommander_get_session
获取单个会话详情（名称/状态/规则匹配）
HTTP Hook API — 监听 127.0.0.1:19527（仅本地，安全隔离）
POST /api/session/:id/status → 更新状态
GET   /api/session/:id/status → 查询单个会话
GET   /api/sessions → 列出所有会话
3

状态实时流转，卡片自动排序

T+0s
用户输入指令 → 状态变为 running
MCP: tcommander_update_status(status="running")
T+3s
AI 开始输出 → PTY 数据流持续写入 xterm buffer，卡片实时预览
terminalPool: onSessionOutput → xterm.write()
T+12s
AI 请求确认修改 → needs-confirm，卡片自动置顶 + Y/N 按钮出现
规则匹配: sys-confirm-yn (contains "y/n") → needs-confirm
T+13s
用户点击 Y → 发送 'y\r'，状态回到 running
sendInput(sessionId, 'y\r') → handleDismissStatus → running
T+30s
任务完成，10s 无活动 → idle，卡片回到普通位置
IDLE_THRESHOLD_MS = 10000 → sortSessions 降级排序
⚙

终端实例池：卡片即终端

一会话一 xterm
每个会话独立 Terminal 实例 + containerDiv，动态 import xterm.js
DOM 转移
双击进全屏 = appendChild 转移 containerDiv，不销毁不重建
零 CPU 休眠
不可见时 detach，buffer 持续 write 但不渲染
异步安全
pendingData 缓存(256KB) + destroyed Set 防竞态 + 双 rAF 延迟 open
CARD_FONT_SIZE = 10 // 卡片预览字体
FULLSCREEN_FONT_SIZE = 13 // 全屏终端字体
SCROLLBACK = 10000 // 滚动缓冲行数
PENDING_BYTE_LIMIT = 256KB // 异步缓存上限（防 OOM）
4

多会话协同，一键响应

⚠ 智能排序
error(0) > needs-confirm(1) > needs-input(2) 自动置顶，基于 stableActivityAt 防抖
⚡ 快捷操作
Y/N（仅需确认时）、⌘C 中断、↑↓ 历史命令、Copy 复制、Enter 确认
📺 全屏切换
双击进入全屏，DOM 转移保留完整 buffer，Ctrl+Alt+←→切换会话
💾 环境恢复
快照保存所有会话配置，重启后一键恢复完整工作环境
🛡 6 条系统默认状态检测规则
sys-error → error
sys-confirm-yn → needs-confirm
sys-confirm-question → needs-confirm
sys-confirm-choice → needs-confirm
sys-trust-folder → needs-confirm
sys-needs-input → needs-input
